# Fork-JEPA project website

Anonymous project page for *Two Actions from One State: Fork Futures Teach JEPA World Models to Compare*.

## Build and preview

Run `python3 scripts/build.py` to validate local references and produce the static `dist/` folder. Serve that folder with `python3 -m http.server 8000 --directory dist`.


Website template from: https://universal-simulator.github.io/unisim/

The interactive gallery includes 46 recorded examples from `T-JEPA_code/gif_gallery`, grouped by task. Original provenance and checksums are preserved in `static/media/gallery/manifest.json`. Clips are qualitative selections, not aggregate success estimates.
