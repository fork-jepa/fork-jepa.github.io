# Fork-JEPA project website

Anonymous project page for *Two Actions from One State: Fork Futures Teach JEPA World Models to Compare*.

## Build and preview

Run `python3 scripts/build.py` to validate local references and produce the static `dist/` folder. Serve that folder with `python3 -m http.server 8000 --directory dist`.


Website template from: https://github.com/le-wm/le-wm.github.io
